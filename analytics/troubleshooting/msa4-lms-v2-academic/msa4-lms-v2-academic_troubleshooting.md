## 2026-08-14 최초 현재학기 동시 생성

### 원인

현재학기 변경 시 기존 행을 잠그는 로직은 있었지만 기존 현재학기가 없는 최초 생성 시에는 잠글 행이 없어 두 요청이 모두 `is_current = 1`로 저장될 수 있었다.

### 해결

MySQL 생성 컬럼이 현재학기 행에서만 상수 `1`을 만들도록 하고 해당 컬럼에 UNIQUE 제약을 추가했다. 일반 학기 행은 `NULL`이어서 여러 건 저장할 수 있다.
기존 현재학기 변경은 새 행 INSERT 전에 해제 UPDATE를 flush하도록 순서를 고정했다.

### 적용 순서

기존 DB에는 애플리케이션 배포 전에 현재학기가 한 건 이하인지 확인하고 `src/main/resources/migration/20260814_add_single_current_semester_unique.sql`을 실행한다.
