# msa4-lms-v2-academic 트러블슈팅

최종 수정일: 2026-08-14

## 2026-08-14 교수 조회 서비스 권한 누락

### 원인

교수 목록과 상세 조회는 컨트롤러의 `@PreAuthorize`만 사용해 서비스가 다른 경로에서 직접 호출될 때 ADMIN 권한을 확인하지 않았다.

### 해결

조회 서비스 진입점에서도 `CurrentUser`의 ADMIN 권한을 검사하고 컨트롤러가 인증 사용자를 전달하도록 변경했다.

## 2026-08-14 공지 본문 무제한 입력

### 원인

공지 본문에 입력 길이 상한이 없어 요청 크기와 저장 데이터 크기를 애플리케이션에서 제한하지 않았다.

### 해결

등록·수정 DTO와 서비스 검증에 5,000자 상한을 동일하게 적용했다.

## 2026-08-14 브라우저 보안 헤더 누락

### 원인

Security 설정에 기본 브라우저 보안 헤더만 적용되어 콘텐츠 출처, 리퍼러 전송, 브라우저 기능 권한 정책이 명시되지 않았다.

### 해결

`SecurityFilterChain`에 CSP, Referrer-Policy, Permissions-Policy를 명시적으로 추가했다.

## 2026-08-14 계약 외 사용자 역할 영속 허용

### 원인

Academic 영속 역할 enum에 사용자 계약에서 허용하지 않는 `SYSTEM`이 포함되어 있었다.

### 해결

영속 enum을 학생, 교수, 관리자 역할만 표현하도록 축소하고 허용 목록을 테스트로 고정했다.

## 2026-08-14 공지 논리 삭제 HTTP 메서드 불일치

### 원인

행을 제거하지 않고 활성 상태만 변경하는 동작을 `DELETE /{noticeId}`로 노출했다.

### 해결

상태 하위 리소스를 수정하는 `PATCH /{noticeId}/status`로 엔드포인트를 변경하고 OpenAPI 계약을 함께 갱신했다.

## 2026-08-14 더미 학기 개강일 불일치

### 원인

2026년 1학기 더미데이터 개강일이 확정 일정과 하루 차이 나는 `2026-03-03`으로 입력되어 있었다.

### 해결

개강일을 `2026-03-02`로 교정하고 통합 테스트가 해당 값을 확인하도록 추가했다.
